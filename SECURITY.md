# Security policy

Please do not report suspected vulnerabilities with session logs or secrets in
public Issues. Contact `jermaine123123` through the private GitHub security
advisory flow for this repository and include a minimal reproduction, affected
adapter/version and sanitized logs.

The project is a local community tool and does not operate a separate security
mailbox. If private advisories are unavailable, open a public issue containing
only the words `security contact requested`; do not include exploit details
until a private channel is established.
