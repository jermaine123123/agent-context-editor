# Pi Context Desktop 0.1.4

This release is a Windows x64 community build from the `context-editor-v0.1`
branch at commit `8378ef51ec2f96c48e5045d99c1069ff8529922b`. It is unsigned and
not an official Pi distribution. The source fork keeps `justhil/pi-app` as
`upstream`; the follow-up `context-units` work is published separately and is
not mixed into this installer release.

Assets:

- `Pi Context Desktop-Setup-0.1.4-x64.exe`
- `Pi Context Desktop-Portable-0.1.4-x64.exe`
- `SHA256SUMS.txt`

Known limitations: Windows x64 only, unsigned community binaries, and no
context exclusion or token compression.
