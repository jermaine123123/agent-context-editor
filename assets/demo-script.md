# 15-second synthetic demo

The release demo uses only the three SVG frames in this directory and a
synthetic session. It never records a real prompt or Session log.

1. 0–4s: show `demo-search.svg`; search for `deployment` and point out counts
   per editable unit.
2. 4–9s: show `demo-reasoning-hidden.svg`; hide reasoning while the answer
   remains shown.
3. 9–15s: show `demo-restore.svg`; restore, restart the profile and point out
   that the sidecar state returns while the original Session is unchanged.
